## Method for each monthly check

1. Open the free Perplexity app. Ask the same three buyer questions, worded exactly as in day 0.
2. Paste each answer below the heading for that month, in full.
3. Count citation markers per domain. Record Dot's count and every competitor's count.
4. Note the date and that it was Perplexity, free app, web search on.

Never estimate a count. If a question was not asked that month, write "not asked", not 0.
