# Post A · piece 1 · the stake first

Choosing an AI data analyst? Don't trust the accuracy score until you've checked one setting.

We ran a 20-question accuracy test in Dot. It scored 100%.

One answer still didn't match the test: average order value, 137.04 against 137.75.

Both numbers were right. The test counted every order. Dot counted delivered orders only, as its context note said.

The score passed it because the test row never said which orders to count.

The full test, the four things to check, and the one-row fix: link in the first comment.
